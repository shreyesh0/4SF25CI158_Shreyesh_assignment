Description
This repository contains 13 Python/Pandas exercises demonstrating DataFrame creation and manipulation, handling missing values, aggregation, merging, MultiIndex operations, applying functions, and text processing.
Topics Covered
1. DataFrame creation and product of columns
2. Row-wise and column-wise sums
3. Handling missing values using column mean
4. Dropping rows containing missing values
5. GroupBy aggregation (sum and mean)
6. Grouping and calculating total sales
7. Merging DataFrames
8. MultiIndex indexing and slicing
9. MultiIndex aggregation
10. Applying functions to DataFrames
11. Lambda functions and row-wise sum
12. String conversion to uppercase
13. Extracting substrings
Libraries Used
- Python
- Pandas
- NumPy
How to Run
1. Open Pandas_Assignment.ipynb in Google Colab or Jupyter Notebook.
2. Run the cells from top to bottom.
Note
Random values are generated during execution, so the displayed outputs may differ each time the notebook is run.
